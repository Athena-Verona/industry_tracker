# IT industry in Lithuania tracker
A solution that tracks the IT industry in Lithuania and generates useful reports. For spring 2025 Innovation Workshops, under the company Baltic Amadeus.
## Project goals
+ Succesfully scrape the web for comptetitors data, such as job openings, company revenue growth and new projects. 
+ Implement an AI model that analyses said data and provides a meaningful report 
+ Create a user-friendly dashboard/report/spreadsheet with clear results. Implement automatic updating.
